# Журнал зала

Веб-приложение для телефона: подходы, утренний вес, талия, пробежки. Ставится на экран «Домой» на iPhone и работает без сети.

Данные не хранятся в этом репозитории. Приложение пишет их через GitHub API в отдельный **приватный** репозиторий владельца. Токен вводится в настройках приложения и остаётся только на устройстве.

## Формат данных в приватном репозитории

| Файл | Что внутри |
|---|---|
| `program.json` | Программа: фазы цикла, расписание, упражнения, ориентиры |
| `workouts/ГГГГ-ММ-ДД.json` | Тренировка за день: тип, подходы `{w, r}`, пробежка, заметка |
| `body/ГГГГ-ММ.json` | По датам за месяц: утренний вес, шаги, талия, низ живота |
| `food/ГГГГ-ММ.json` | По дням: отмеченные приёмы пищи, сладкое, принятые добавки |

## Установка на iPhone

1. Открыть сайт приложения в Safari.
2. «Поделиться» → «На экран „Домой“».
3. Открыть приложение с иконки → настройки → вставить fine-grained токен GitHub с доступом `Contents: Read and write` только к приватному репозиторию с данными.

Код без зависимостей и сборки: `index.html`, `app.css`, `app.js`, `sw.js`.

## Ночной лайм · версия 7

Стартовый экран «Обзор» показывает результаты из существующих записей. Три основные вкладки: обзор, тренировка и еда. Вес и замеры, история и программа открываются из обзора. Вся тренировка остаётся одним списком. Системный шрифт и тёмная палитра работают без загрузки внешних шрифтов.

Схема JSON и ключ `sport-journal.v1` не изменены. При первом открытии версии 7 прежний локальный снимок, включая очередь отправки, копируется в `sport-journal.backup.before-night-v1`. Снимок не заменяется при последующих запусках. Если браузер не разрешил создать копию, в настройках показывается сообщение. В настройках можно скачать текущие записи или копию до обновления; файл включает пути, SHA и очередь, но исключает токен. Автоматического импорта этих файлов в интерфейсе пока нет.

Синхронизация повторно проверяет локальные правки после загрузки файла. При конфликте с другой версией на GitHub она сохраняет локальную очередь и останавливает отправку; удалённый файл не перезаписывается. Если удалённое содержимое уже совпадает с отправляемым, запрос считается выполненным. Обновление оболочки не очищает localStorage и не перезагружает открытый редактор принудительно.

Автоматический расчёт произвольной еды и импорт Apple Health в эту версию не входят. Неуказанные калории и белок отмечаются отдельно от нулевых значений.

В разделах «Тренировка», «Еда» и «Вес и замеры» можно нажать на дату, чтобы раскрыть календарь. В нём есть переключение месяцев, выделение выбранного дня и кнопка «Сегодня». Стрелки рядом с датой по-прежнему переключают дни. Календарь работает без сети. Для управления с клавиатуры доступны стрелки, Home/End, PageUp/PageDown и Escape.

Для телефона задано `touch-action: manipulation`: двойной тап не должен увеличивать страницу, прокрутка и масштабирование двумя пальцами сохраняются. Поля ввода имеют размер шрифта от 16 px.

## Проверка мобильного интерфейса

При установленном Node.js, Playwright и Chrome: `node tests/mobile.cjs`. Если Playwright находится в отдельном каталоге, укажи его через `NODE_PATH`. Для сохранения скриншотов задай `TEST_ARTIFACT_DIR` вне репозитория приложения.

Проверки используют отдельный профиль браузера, синтетические записи и локальный HTTP-сервер. Проверяются выбор дат, сохранение записей, високосный год, клавиатура, восемь размеров экрана, обе темы и работа без сети. Настоящий токен и приватный GitHub не нужны. Поведение Safari, жестов и клавиатуры на физическом iPhone проверяется отдельно.

`node tests/data-preservation.cjs` проверяет старый формат, очередь отправки, неизвестные поля, резервные копии, конфликт GitHub и ввод во время загрузки. `PREVIOUS_APP_REF=15ef68eaf28ce2aa3e703e165738f0b61bf506ac` задаёт опубликованную старую версию для проверки обновления service worker v5 → v7 без потери локальных записей.
