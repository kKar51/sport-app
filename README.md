# Журнал зала

Веб-приложение для телефона: подходы, утренний вес, талия, пробежки. Ставится на экран «Домой» на iPhone и работает без сети.

Данные не хранятся в этом репозитории. Приложение пишет их через GitHub API в отдельный **приватный** репозиторий владельца. Токен вводится в настройках приложения и остаётся только на устройстве.

## Формат данных в приватном репозитории

| Файл | Что внутри |
|---|---|
| `program.json` | Программа: фазы цикла, расписание, упражнения, ориентиры |
| `workouts/ГГГГ-ММ-ДД.json` | Тренировка за день: тип, подходы `{w, r}`, пробежка, заметка |
| `body/ГГГГ-ММ.json` | Утренний вес и талия за месяц по датам |

## Установка на iPhone

1. Открыть сайт приложения в Safari.
2. «Поделиться» → «На экран „Домой“».
3. Открыть приложение с иконки → настройки → вставить fine-grained токен GitHub с доступом `Contents: Read and write` только к приватному репозиторию с данными.

Код без зависимостей и сборки: `index.html`, `app.css`, `app.js`, `sw.js`.
