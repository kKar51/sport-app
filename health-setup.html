Сон, шаги и активность с Apple Watch

Один раз собираешь команду на iPhone. Сначала проверяешь её вручную: запуск, вставка в журнал, сверка. Потом включаешь автоматический режим (разделы 8–9): команда сама отправляет вчерашний день в приватный репозиторий, когда утром разблокируешь телефон, и журнал подхватывает его при следующей синхронизации.

Настройка «Команд» на физическом iPhone ещё не проверена. Ниже указаны английские названия действий для поиска; русские подписи могут немного отличаться. Если нужного поля или источника нет, остановись на этом шаге и сообщи его номер — не подставляй вместо него другое значение.

1. Проверь данные и сохрани копию

  1. Открой «Здоровье» → «Обзор» → «Активность» → «Шаги». Убедись, что за вчера есть записи. В «Источники данных и доступ» найди свои Apple Watch.
  2. Открой «Здоровье» → «Обзор» → «Сон». Проверь, что есть продолжительность сна и его стадии. В Watch → «Сон» должно быть включено отслеживание сна с Apple Watch. Часы нужно надевать на ночь. Инструкция Apple.
  3. В журнале открой настройки → «Скачать копию данных». Сохрани файл в «Файлы».

2. Создай команду и дату

Открой встроенное приложение «Команды» → «+». Назови команду «Сон и шаги в журнал». Действия добавляй в указанном порядке. Имена переменных ниже нужны, чтобы не перепутать результаты.

  1. «Текущая дата» (Current Date).
  2. «Изменить дату» (Adjust Date): получить начало дня текущей даты. Назови результат Сегодня.
  3. Ещё Adjust Date: вычесть 1 день из Сегодня. Назови результат День.
  4. «Форматировать дату» (Format Date): вход День, формат «Пользовательский» → yyyy-MM-dd. Назови результат ДатаДня. Именно строчные yyyy, не YYYY.
  5. Adjust Date: добавить 12 часов к День. Назови КонецСна.
  6. Adjust Date: вычесть 1 день из КонецСна. Назови НачалоСна.

Например, при запуске 15 октября дата импорта — 14 октября: шаги за 14-е и сон, завершившийся утром 14-го. Сон за сегодняшнюю ночь попадёт в завтрашний импорт. Берём завершённый день, чтобы не сохранять неполные шаги как суточный итог.

3. Получи шаги только с часов

  1. Добавь «Ничего» (Nothing). Это сбрасывает вход для поиска.
  2. «Найти образцы данных Здоровья» (Find Health Samples). Выбери все условия: тип «Шаги», дата начала «вчера», источник — твои текущие Apple Watch. Отключи ограничение количества результатов. Источник выбери из списка, а не вписывай произвольно.
  3. «Количество» (Count) найденных образцов. Добавь «Если» (If) количество равно 0 → «Показать предупреждение» (Show Alert) «Нет шагов часов за вчера. Проверь доступ и источник» → «Остановить эту команду» (Stop This Shortcut). Закрой блок If. Отсутствие доступа нельзя превращать в 0 шагов.
  4. «Получить сведения об образцах данных Здоровья» (Get Details of Health Samples): свойство «Значение» (Value), вход — именно список из шага 11, не результат Count. Можно выбрать Value через свойства синей переменной найденных образцов.
  5. «Вычислить статистику» (Calculate Statistics): операция «Сумма» (Sum), вход — значения из шага 13. Назови результат Шаги.

Шаги с iPhone и Apple Watch нельзя просто сложить: одни и те же перемещения могут присутствовать в обоих источниках. Здесь считаются только часы, поэтому итог может быть ниже общей цифры в «Здоровье», если ты ходил без часов.

4. Получи интервалы сна

  1. Добавь Nothing перед новым поиском. Apple рекомендует это, чтобы следующий Find заново читал данные, а не фильтровал предыдущий результат.
  2. Find Health Samples: тип «Сон» (Sleep), все условия: дата начала раньше КонецСна, дата окончания позже НачалоСна. Это найдёт интервалы, пересекающие окно сна; журнал обрежет лишнее на границах. Выбери один источник Apple Watch, если этот фильтр доступен и возвращает записи. Ограничение количества результатов выключи. Не выбирай только последний образец.
  3. «Повторить с каждым» (Repeat with Each) найденным образцом сна.
  4. Внутри повтора: Format Date, вход — «Элемент повтора» (Repeat Item) → «Дата начала» (Start Date), формат ISO 8601. Назови НачалоИнтервала.
  5. Внутри повтора: второй Format Date, вход — Repeat Item → «Дата окончания» (End Date), формат ISO 8601. Назови КонецИнтервала.
  6. Внутри повтора: «Текст» (Text) из трёх синих переменных, разделённых знаком |: НачалоИнтервала, КонецИнтервала, Repeat Item → Value. Должно получиться примерно 2026-10-13T23:10:00+03:00|2026-10-14T00:20:00+03:00|Базовый. Не вписывай пример вручную. Это последнее действие внутри повтора.
  7. После «Конец повтора»: «Объединить текст» (Combine Text), вход — «Результаты повтора» (Repeat Results), разделитель новые строки. Назови ИнтервалыСна.

Если свойство не видно у синей переменной, используй Get Details of Health Samples с тем же свойством. Значение сна должно быть категорией: Базовый/Core, Глубокий/Deep, Быстрый/REM, В постели/In Bed, Бодрствование/Awake. Журнал исключит бодрствование и время в постели, объединит пересекающиеся интервалы и отнесёт всю ночь к одной дате.

У сна фильтр источника в «Командах» может отличаться от шагов. Если выбрать Watch нельзя, импорт будет из Apple Health без подтверждённого источника; при первом запуске обязательно сравни итог с «Здоровьем». Если сон записывают несколько приложений, лучше сначала импортировать только шаги: оставь блок после sleep: пустым. Для сна используется окно с 12:00 предыдущего дня до 12:00 выбранного дня; дневной сон и сменный режим могут давать отличие от суточной сводки Apple.

5. Получи активные калории и минуты упражнений

  1. Добавь Nothing.
  2. Find Health Samples: тип «Активная энергия» (Active Energy), дата начала «вчера», источник — твои Apple Watch, ограничение количества выключено.
  3. Get Details of Health Samples → Value, затем Calculate Statistics → Sum. Назови результат АктивныеКкал. В «Здоровье» → профиль → «Единицы» энергия должна быть в ккал, не в кДж.
  4. Ещё раз Nothing, затем Find Health Samples: тип «Время упражнений» (Exercise Minutes / Apple Exercise Time), дата начала «вчера», источник — Apple Watch.
  5. Get Details → Value, Calculate Statistics → Sum. Назови МинутыУпражнений.

Если одного из типов нет в списке, пропусти его и оставь строку в шаблоне ниже пустой: пустое значение журнал считает неизвестным, а не нулём.

Проверь заодно: есть ли в списке типов Find Health Samples «Тренировки» (Workouts). Если есть — напиши, это следующий шаг: тип, длительность и калории каждой тренировки с часов. Подходы и веса часы не записывают, их по-прежнему вводишь в журнале.

6. Собери текст

  1. Добавь Text и вставь этот шаблон:
SPORT_HEALTH_V1
date=[ДатаДня]
source=Apple Health
steps=[Шаги]
activeKcal=[АктивныеКкал]
exerciseMin=[МинутыУпражнений]
sleep:
[ИнтервалыСна]

Каждую надпись в квадратных скобках замени синей переменной из соответствующего шага. Скобки в результате оставаться не должны. Не добавляй кавычки или тройные обратные кавычки. Назови результат ДанныеДня.

7. Первая проверка вручную

  1. Временно добавь «Скопировать в буфер обмена» (Copy to Clipboard) с входом ДанныеДня.
  2. Разблокируй iPhone, открой «Здоровье» и дождись свежих записей часов. Запусти команду кнопкой ▶. Разреши чтение шагов, сна, активной энергии и времени упражнений.
  3. Открой журнал → настройки → «Импортировать сон и шаги» → «Вставить из буфера» → «Проверить данные». Сравни дату, шаги, сон и активность с «Здоровьем». Часы сна показываются десятичным числом: 7,5 ч = 7 ч 30 мин.
  4. Если всё верно, нажми «Импортировать». Если появилась ошибка — сохранение не выполняется; сообщи её текст и номер шага, не заменяй результат нулём.
  5. После удачной проверки удали действие «Скопировать в буфер обмена».

8. Автоматическая отправка в GitHub

Для этого команде нужен отдельный токен с правом только на приватный репозиторий журнала. Он хранится внутри команды: никогда не делись этой командой — вместе со ссылкой уйдёт и токен. Потерял телефон — отзови токен на GitHub.

  1. В Safari открой github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Название «iPhone Health», срок — до года. Repository access: Only select repositories → sport. Permissions → Contents: Read and write. Больше ничего не включай. Скопируй токен.
  2. В команде после шага 27: «Кодировать в Base64» (Base64 Encode), вход ДанныеДня, «Разрывы строк» (Line Breaks): «Нет» (None). Назови Содержимое.
  3. Text: https://api.github.com/repos/kKar51/sport/contents/health/auto/[ДатаДня].txt, где [ДатаДня] — синяя переменная. Назови Адрес.
  4. «Получить содержимое URL» (Get Contents of URL): адрес Адрес, метод GET, заголовки: Authorization = Bearer и сразу после пробела токен; Accept = application/vnd.github+json. Назови Ответ.
  5. «Получить значение из словаря» (Get Dictionary Value): ключ sha в Ответ. Затем If результат «имеет любое значение» (has any value) → Stop This Shortcut. Закрой If. Так файл за день отправляется один раз, а повторные запуски ничего не делают.
  6. Ещё один Get Contents of URL: адрес Адрес, метод PUT, те же два заголовка, «Тело запроса» (Request Body): JSON с тремя текстовыми полями: message = Здоровье [ДатаДня], content = Содержимое, branch = main.
  7. Get Dictionary Value: ключ content в результате шага 38. If не имеет значения → «Показать уведомление» (Show Notification) «Здоровье не отправлено» с результатом шага 38. Закрой If.

Запусти команду вручную один раз. В репозитории sport должен появиться файл health/auto/ДАТА.txt, а в журнале после синхронизации — шаги, сон и строка «Часы: активные … ккал · упражнения … мин» на «Обзоре» за вчера с пометкой «автоматически».

9. Запуск без нажатий

  1. «Команды» → «Автоматизация» → «+» → «Приложение» (App). Выбери приложение, которое открываешь каждое утро (например, мессенджер), условие «Открыто» (Is Opened).
  2. «Запускать сразу» (Run Immediately), выключи «Уведомлять при запуске». Действие — запустить эту команду.

Почему приложение, а не время: пока iPhone заблокирован, iOS не отдаёт данные «Здоровья» (ограничение Apple). Открытое приложение означает, что телефон разблокирован. Команда отправит вчерашний день при первом открытии, остальные запуски за день остановятся на шаге 37.

Что попадает в журнал

  • Шаги и активность — за вчера. Сон — ночь, завершившаяся утром вчерашнего дня: сон сегодняшней ночи придёт завтра.
  • Порядок важности: ручной ввод → подтверждённый импорт через вставку → автоматическая отправка. Автоматический файл журнал только читает и никогда не меняет.
  • Если файл не проходит проверку (неизвестная категория сна, неверная дата), журнал его не учитывает, существующие записи не меняются.

Поддержку дат ISO 8601 описывает руководство Apple. Импортёр проверен на синтетических данных; точные действия и разрешения на твоём iPhone требуют первого запуска по этой инструкции.
