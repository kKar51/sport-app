Сон и шаги без дополнительных приложений

Один раз собираешь команду на iPhone. Дальше запускаешь её, открываешь журнал и вставляешь результат. Это импорт по твоему действию: фоновой передачи пока нет. Токен GitHub в команду добавлять не нужно.

Настройка «Команд» на физическом iPhone ещё не проверена. Ниже указаны английские названия действий для поиска; русские подписи могут немного отличаться. Если нужного поля или источника нет, остановись на этом шаге и сообщи его номер — не подставляй вместо него другое значение.

1. Проверь данные и сохрани копию

  1. Открой «Здоровье» → «Обзор» → «Активность» → «Шаги». Убедись, что за вчера есть записи. В «Источники данных и доступ» найди свои Apple Watch.
  2. Открой «Здоровье» → «Обзор» → «Сон». Проверь, что есть продолжительность сна и его стадии. В Watch → «Сон» должно быть включено отслеживание сна с Apple Watch. Часы нужно надевать на ночь. Инструкция Apple.
  3. В журнале открой настройки → «Скачать копию данных». Сохрани файл в «Файлы».

2. Создай команду и дату

Открой встроенное приложение «Команды» → «+». Назови команду «Сон и шаги в журнал». Действия добавляй в указанном порядке. Имена переменных ниже нужны, чтобы не перепутать результаты.

  1. «Текущая дата» (Current Date).
  2. «Изменить дату» (Adjust Date): получить начало дня текущей даты. Назови результат Сегодня.
  3. Ещё Adjust Date: вычесть 1 день из Сегодня. Назови результат День.
  4. «Форматировать дату» (Format Date): вход День, формат «Пользовательский» → yyyy-MM-dd. Назови результат ДатаДня. Именно строчные yyyy, не YYYY.
  5. Adjust Date: добавить 12 часов к День. Назови КонецСна.
  6. Adjust Date: вычесть 1 день из КонецСна. Назови НачалоСна.

Например, при запуске 15 октября дата импорта — 14 октября: шаги за 14-е и сон, завершившийся утром 14-го. Сон за сегодняшнюю ночь попадёт в завтрашний импорт. Берём завершённый день, чтобы не сохранять неполные шаги как суточный итог.

3. Получи шаги только с часов

  1. Добавь «Ничего» (Nothing). Это сбрасывает вход для поиска.
  2. «Найти образцы данных Здоровья» (Find Health Samples). Выбери все условия: тип «Шаги», дата начала «вчера», источник — твои текущие Apple Watch. Отключи ограничение количества результатов. Источник выбери из списка, а не вписывай произвольно.
  3. «Количество» (Count) найденных образцов. Добавь «Если» (If) количество равно 0 → «Показать предупреждение» (Show Alert) «Нет шагов часов за вчера. Проверь доступ и источник» → «Остановить эту команду» (Stop This Shortcut). Закрой блок If. Отсутствие доступа нельзя превращать в 0 шагов.
  4. «Получить сведения об образцах данных Здоровья» (Get Details of Health Samples): свойство «Значение» (Value), вход — именно список из шага 11, не результат Count. Можно выбрать Value через свойства синей переменной найденных образцов.
  5. «Вычислить статистику» (Calculate Statistics): операция «Сумма» (Sum), вход — значения из шага 13. Назови результат Шаги.

Шаги с iPhone и Apple Watch нельзя просто сложить: одни и те же перемещения могут присутствовать в обоих источниках. Здесь считаются только часы, поэтому итог может быть ниже общей цифры в «Здоровье», если ты ходил без часов.

4. Получи интервалы сна

  1. Добавь Nothing перед новым поиском. Apple рекомендует это, чтобы следующий Find заново читал данные, а не фильтровал предыдущий результат.
  2. Find Health Samples: тип «Сон» (Sleep), все условия: дата начала раньше КонецСна, дата окончания позже НачалоСна. Это найдёт интервалы, пересекающие окно сна; журнал обрежет лишнее на границах. Выбери один источник Apple Watch, если этот фильтр доступен и возвращает записи. Ограничение количества результатов выключи. Не выбирай только последний образец.
  3. «Повторить с каждым» (Repeat with Each) найденным образцом сна.
  4. Внутри повтора: Format Date, вход — «Элемент повтора» (Repeat Item) → «Дата начала» (Start Date), формат ISO 8601. Назови НачалоИнтервала.
  5. Внутри повтора: второй Format Date, вход — Repeat Item → «Дата окончания» (End Date), формат ISO 8601. Назови КонецИнтервала.
  6. Внутри повтора: «Текст» (Text) из трёх синих переменных, разделённых знаком |: НачалоИнтервала, КонецИнтервала, Repeat Item → Value. Должно получиться примерно 2026-10-13T23:10:00+03:00|2026-10-14T00:20:00+03:00|Базовый. Не вписывай пример вручную. Это последнее действие внутри повтора.
  7. После «Конец повтора»: «Объединить текст» (Combine Text), вход — «Результаты повтора» (Repeat Results), разделитель новые строки. Назови ИнтервалыСна.

Если свойство не видно у синей переменной, используй Get Details of Health Samples с тем же свойством. Значение сна должно быть категорией: Базовый/Core, Глубокий/Deep, Быстрый/REM, В постели/In Bed, Бодрствование/Awake. Журнал исключит бодрствование и время в постели, объединит пересекающиеся интервалы и отнесёт всю ночь к одной дате.

У сна фильтр источника в «Командах» может отличаться от шагов. Если выбрать Watch нельзя, импорт будет из Apple Health без подтверждённого источника; при первом запуске обязательно сравни итог с «Здоровьем». Если сон записывают несколько приложений, лучше сначала импортировать только шаги: оставь блок после sleep: пустым. Для сна используется окно с 12:00 предыдущего дня до 12:00 выбранного дня; дневной сон и сменный режим могут давать отличие от суточной сводки Apple.

5. Скопируй результат

  1. Добавь Text и вставь этот шаблон:
SPORT_HEALTH_V1
date=[ДатаДня]
source=Apple Health
steps=[Шаги]
sleep:
[ИнтервалыСна]

Каждую надпись в квадратных скобках замени синей переменной из соответствующего шага. Скобки в результате оставаться не должны. Не добавляй кавычки или тройные обратные кавычки.

  1. «Скопировать в буфер обмена» (Copy to Clipboard): вход — текст шага 22.
  2. Show Alert: «Данные скопированы. Открой журнал → настройки → Сон и шаги → Вставить». Сохрани команду.

6. Первый запуск и импорт

  1. Разблокируй iPhone, открой «Здоровье» и дождись появления свежих записей часов. Запусти команду кнопкой ▶. Разреши чтение шагов и сна, когда iOS спросит. Запись в «Здоровье» этой команде не нужна.
  2. Открой свой установленный журнал, затем настройки → «Импортировать сон и шаги». Нажми «Вставить из буфера». Если браузер не даёт читать буфер, удерживай поле текста → «Вставить».
  3. Нажми «Проверить данные». Сравни дату, шаги часов и сон с «Здоровьем». Часы показываются десятичным числом: 7,5 ч = 7 ч 30 мин.
  4. Если всё верно, нажми «Импортировать». Откроется выбранный день в «Вес и замеры». Повторный импорт не складывает значения повторно. Уже введённые вручную значения остаются основными; импорт хранится отдельно.
  5. При подключённом GitHub дождись обычного статуса «В GitHub». Передаются только подготовленные сон и шаги. Команда сама ничего не отправляет в сеть.

Если появилась неизвестная категория сна, ошибка даты или пустые данные — сохранение не выполняется. Сообщи текст ошибки; существующие записи останутся на месте. На первом запуске не исправляй ошибку заменой результата на 0.

Каждый день

Запустить команду → открыть журнал → «Вставить из буфера» → «Проверить данные» → «Импортировать». Команду можно вынести на экран «Домой». Автоматическую отправку по расписанию этот вариант не делает. На заблокированном iPhone чтение здоровья может быть недоступно: ограничение Apple.

Поддержку дат ISO 8601 описывает руководство Apple. Работа импортёра проверяется отдельно на синтетических данных; точные действия и разрешения на твоём iPhone требуют первого запуска по этой инструкции.
